# BubblesBot

A small Python + Playwright bot that automatically updates my Instagram Note with a random funny dog phrase. My pfp is currently my sisters dog and the note section for instagram fits very closely to his head. This bot makes it 
look like he is thinking about a randomly chosen word.

It uses a persistent Chrome session and is designed to run once per day through Windows Task Scheduler.

## Run

```bash
pip install playwright
playwright install
python script.py
